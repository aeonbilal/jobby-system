# Judge rubric: application letters and CVs (generic; candidate facts live in candidates/<slug>/judge-rubric-facts.md)

Evaluate each assigned letter (the body between the two "---" markers in email-pack.md) against these rules. Report findings only; do NOT edit files.

GROUNDING (read candidates/<slug>/dossier.md FIRST, plus candidates/<slug>/judge-rubric-facts.md if present; every claim must trace to them):
G1. No duration may attach to a tool/software/skill (e.g. "four years on ABELdent" is a violation; "four years owning scheduling, with ABELdent fluency" is fine). Durations attach only to dossier-evidenced work.
G2. No certification/enrollment claims beyond the dossier ("plans to complete" is the ceiling unless the dossier says enrolled or held). Candidate-specific held/not-held facts: see judge-rubric-facts.md.
G3. Scope: never promise regulated acts the candidate cannot legally perform in the target province (see the dossier constraints).
G4. Numbers must match the dossier narrative bank exactly (including approximators).
G5. No invented employer facts (claims about the employer must be plausible from the pack's own metadata).

TONE:
T1. Formal, professional register. No quirky intensifiers ("unusually well", "genuinely like").
T2. Never needy: no "prove myself", "promise complete commitment", begging constructions.
T3. Honest-but-confident: transparency paragraphs (e.g. licensure status, domain humility) are deliberate and stay; they must read as confidence, not apology.
T4. "I would be glad to" over "I would love to".

FORM:
F1. No em-dashes anywhere.
F2. Exactly one signature block (the candidate's name and post-nominal, once).
F3. Correct employer name throughout; no other employer's name in the letter.

HYBRID TAILORING (CVs, RESUME-STANDARD §12):
H1. Zone 1 coverage: the headline carries the posting's exact title. The posting's top 5 requirements appear verbatim in the headline, profile, or Skills wherever the dossier supports them. Each missing one is either a recorded gap or a FIX.
H2. Zone 2 voice: experience bullets must not read as the job ad reflected back. FIX if a bullet copies the duties wording without the candidate's own specifics, or if posting terms are pasted onto work the candidate didn't do.
H3. Zone 2 selection: relevant work first. Notable achievements the posting didn't ask for stay, unless they crowd relevant ones off page 1.
H4. No unsupported requirement anywhere. Unmet requirements are listed under `## Gaps` in the pipeline file.

ACCOMPLISHMENTS (CVs, RESUME-STANDARD §13):
A1. Classify every bullet as Q, R, S or D. FIX any D bullet unless it is a posting must-have with a logged question for the candidate. FIX if D is more than 1 per role or more than 20% overall.
A2. HOW: every Q and R bullet names the method. A result with no HOW is a FIX.
A3. Numbers: each one traces to a narrative-bank entry and keeps its approximator ("~", "20+"). A number with no dossier tag, or one that was rounded up, is a G-level failure.
A4. Qualitative evidence: R bullets name a real evidence type (scope, recognition, first/only, adoption, before/after, comparative, relied-on, trust). Intensity adverbs are not evidence.
A5. Profile: contains 1–2 Q/R accomplishments, not adjectives.
A6. Blacklist (§13.5): any FAIL-list phrase is a FIX. WARN-list phrases need a result or HOW in the same bullet.
A7. Projects: present only if the §13.7 criteria hold; never padding.

For each letter output:
FILE | VERDICT: PASS or FIX | findings as "RULE: exact quote -> why -> suggested rewrite" (one per finding)
Be strict on G-rules, proportionate on T-rules (do not flatten personality where register fits the audience, e.g. fitness studios).
